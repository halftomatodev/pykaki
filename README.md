# PyKaki

**파이썬을 몰라도 렌파이(Ren'Py) 대본을 쓸 수 있는 웹 에디터예요.**
상자와 선으로 이야기 흐름을 그리고, 대사를 쓰고, 렌파이 스크립트(`.rpy`)로 내보내요.

👉 **바로 쓰기: https://halftomatodev.github.io/pykaki/**
(크롬이나 엣지를 추천해요. 설치나 회원가입은 필요 없어요.)

## 할 수 있는 것

- 상자(대사 묶음)와 선(흐름)으로 대본 쓰기, 선택지와 분기
- 배경 바꾸기, 캐릭터 보이기/숨기기, 배경음악, 효과음을 **명령 없이 칸만 채워서** 넣기
- 줄을 끌어서 순서 바꾸기
- 렌파이 대화창처럼 미리 플레이해 보기
- 문제(연결 안 된 선, 빈 대사, 잘못된 이름) 검사
- `.rpy`로 내보내기
- 집중 모드(화면을 비우고 쓰는 줄만 또렷하게), 화면 색·글꼴(Neo둥근모)·단축키 바꾸기

자세한 사용법은 [사용 가이드](docs/GUIDE.md)를 보세요.

## 내 대본은 어디에 저장되나요?

서버가 없어요. 대본은 **내 브라우저와 내 컴퓨터에만** 있어요.

- 자동 저장: 브라우저 안. 브라우저 데이터를 지우면 사라져요.
- **[저장](Ctrl+S)으로 만드는 `.flow.json` 파일이 진짜 백업**이에요. 다른 컴퓨터에서 이어 쓸 때도 이 파일을 [열기]로 불러와요.

## 직접 고쳐서 쓰기 (개발자용)

```bash
npm install      # 처음 한 번
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/index.html 한 파일로 빌드
```

`main` 브랜치에 올리면 GitHub Actions가 GitHub Pages로 배포해요.
구현 명세는 [docs/SPEC.md](docs/SPEC.md)에 있어요.
